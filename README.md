# نظام إدارة مخازن (إضافة، تعديل، حذف، تتبع المنتجات)
==============================================

## Overview & Project Purpose
---------------

نظام إدارة مخازن هو تطبيق ويب يسمح للمستخدمين بإدارة مخازنهم بسهولة ويسر. يتيح النظام إضافة وتعديل وحذف وتتبع المنتجات في المخزن. يهدف النظام إلى توفير حل متكامل لإدارة المخازن، مما يقلل من الأخطاء ويحسن كفاءة العمل.

## Project Structure Mapping
-------------------------

* `app`: تطبيق الويب
	+ `models`: نماذج البيانات
	+ `views`: مناظير التطبيق
	+ `templates`: قوالب التطبيق
	+ `static`: الملفات الثابتة
* `database`: قاعدة البيانات
* `docker`: ملفات الدوكر
* `requirements`: متطلبات التطبيق

## Running the Environment
-------------------------

لتشغيل التطبيق، اتبع الخطوات التالية:

1. قم بتثبيت دوكر ودوكر كومبوز على جهازك.
2. قم بتشغيل الأمر `docker-compose up` في المجلد الجذر للتطبيق.
3. انتظر حتى يتم تشغيل التطبيق.
4. افتح متصفحك وادخل إلى الرابط `http://localhost:8000`.

## Modules, Tables, and Roles
---------------------------

### Modules

* `products`: إدارة المنتجات
* `warehouses`: إدارة المخازن
* `users`: إدارة المستخدمين

### Tables

* `products`: جدول المنتجات
* `warehouses`: جدول المخازن
* `users`: جدول المستخدمين
* `product_warehouse`: جدول المنتجات في المخزن

### Roles

* `admin`: مدير النظام
* `user`: مستخدم النظام
